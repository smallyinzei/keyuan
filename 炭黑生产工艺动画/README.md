## 数据口径

- **课件**：工艺顺序、设备名称、280 ℃ / 850 ℃ / ≤250 ℃ / 200～300 ℃、K₂CO₃ 结构控制剂、尾气 1/3 : 2/3、倾注密度（粉状 0.03～0.048、造粒 0.3～0.5 g/cm³）。
- **公司资料**：富芳烃油原料、重金属未检出、45 µm 筛余物 TDS ≤500 ppm / 内控 ≤300 ppm、加热减量 ≤0.8%、细粉 ≤7.0%、颗粒强度 30±10 cN、包装规格、三大基地牌号、规划总产能 100 万吨、尾气替代天然气、自产蒸汽替代外购蒸汽。
- **行业通用**：反应温度“1300 ℃ 以上”，以及“粒径越细，收率越低”，来自 US EPA AP-42 §6.1 Carbon Black（1320～1540 ℃；小粒径炭黑收率最低）。“橡胶用炭黑绝大多数采用油炉法”也依据该文件（油炉法约占 90%）。粒径区间（N220 20–25 nm 等）与相对价格沿用《炭黑产品话术 v0.3》中的【通】口径。

## 使用前需要确认的几点

1. **筛余物口径不一致**：课件第 20 页写“45 µm 筛余物一般控制在 ≤0.3%”（= 3000 ppm），公司介绍资料写的是国标 ≤1000 ppm。视频采用 TDS（≤500 ppm）和介绍资料（内控 ≤300 ppm）的口径。对外报价以哪份为准，仍按话术文档里的【待确认】处理。
2. **课件两处说法不同**：第 7 页第（4）段写干燥废气经袋滤器后由排气筒排放，第（5）段写尾气燃烧后的烟气经脱硫脱硝再由烟囱排放。视频两处都按原文呈现，没有合并。
3. **1/3 : 2/3 的尾气分配**出自课件对某一装置的描述，各基地的实际比例未核实。
4. **对外播放**：片中有内部课件内容和内控指标。给客户看之前，建议先请张师傅确认。片中只使用“长鸿炭黑”品牌和基地地名，不出现集团名称。
5. 画面是原理示意图，设备外形与实际装置不同。

## 修改与重新渲染

```bash
pip install playwright imageio-ffmpeg fonttools brotli
# 字体：Noto Sans SC 可变字体（SIL OFL 1.1），放到 ~/.fonts/NotoSansSC-VF.ttf
python src/build.py                 # 生成单文件 HTML（内嵌字体子集）
python src/render.py video          # 渲染 MP4（Chromium 路径可用环境变量 CHROME 指定）
python src/render.py srt            # 导出字幕
python src/render.py preview 95 115 # 截取指定秒数的画面检查
```

字幕和画面的时间都写在 `src/scenes.js` 各场景的 `caps` 与 `update()` 中。改完文字后重新执行 `build.py` 和 `render.py` 即可。
